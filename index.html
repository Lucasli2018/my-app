ⓘ 为何需要代理 / 如何部署转发 Worker
Cloudflare 官方 API（api.cloudflare.com）不返回任何 CORS 头，浏览器无法直连（已实测确认）。 需部署一个极简 Worker 做转发并补上 CORS 头：
① 打开 dash.cloudflare.com → Workers & Pages → 创建 Worker；
② 粘贴以下代码并部署，把得到的地址填入上方「代理地址」： 
export default {
  async fetch(request){
    if(request.method==='OPTIONS') return new Response(null,{status:204,headers:{
      'Access-Control-Allow-Origin':'*',
      'Access-Control-Allow-Methods':'GET,POST,PUT,PATCH,DELETE,OPTIONS',
      'Access-Control-Allow-Headers':'Authorization,Content-Type'}});
    const u=new URL(request.url);
    const init={method:request.method,headers:request.headers};
    if(!['GET','HEAD'].includes(request.method)) init.body=await request.arrayBuffer();
    const resp=await fetch('https://api.cloudflare.com'+u.pathname+u.search, init);
    const h=new Headers(resp.headers);
    h.set('Access-Control-Allow-Origin','*');
    h.set('Access-Control-Allow-Methods','GET,POST,PUT,PATCH,DELETE,OPTIONS');
    h.set('Access-Control-Allow-Headers','Authorization,Content-Type');
    return new Response(resp.body,{status:resp.status,headers:h});
  }
}
🔐 所有凭据仅保存在你当前浏览器的 localStorage 中，不会上传到任何服务器（除目标平台官方 API 外）。 换浏览器或清缓存会丢失，请妥善保管令牌。
